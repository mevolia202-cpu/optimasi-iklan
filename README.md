# Kalkulator Budget & ROAS Iklan Shopee

Aplikasi web statis (satu file HTML, tanpa dependensi) berisi kalkulator margin/ROAS, alokasi budget marketing, dan tracker iklan harian. Data tersimpan di localStorage peramban.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub (mis. `kalkulator-budget-shopee`).
2. Upload `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Tunggu 1-2 menit; alamat situs muncul di halaman yang sama: `https://USERNAME.github.io/kalkulator-budget-shopee/`.
